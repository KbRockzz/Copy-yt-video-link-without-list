# Copy-yt-video-link-without-list

Chrome extension popup to copy the active YouTube URL.

## Features

- Copy the current tab URL when you are on YouTube.
- Toggle removal of the `list` parameter (on by default).
- Keeps the toggle preference using Chrome sync storage.

## Load in Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the repository folder you cloned/downloaded locally.
